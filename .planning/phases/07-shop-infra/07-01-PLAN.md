Thay khối `webDist` hiện tại (dòng 39–61) bằng cơ chế chọn dist theo `Host`.

1. Khai báo cả hai đường dẫn:
   `const webDist = join(process.cwd(), 'web-dist');`
   `const shopDist = join(process.cwd(), 'shop-dist');`

2. Thêm helper thuần, đặt trên `bootstrap()`:
   ```ts
   // M2.D-66 — order.<domain> phục vụ app khách, còn lại phục vụ app quản lý.
   // Strip port trước khi so (order.localhost:3001 → order.localhost) để test local
   // bằng curl -H "Host: order.localhost" đi đúng nhánh.
   function isShopHost(host: string | undefined): boolean {
     const h = (host || '').split(':')[0].toLowerCase();
     return h.startsWith('order.');
   }
   ```

3. Import `express` (`import express from 'express';`) và tạo 2 static handler, mount qua một middleware chọn theo host:
   ```ts
   const hasWeb = existsSync(webDist);
   const hasShop = existsSync(shopDist);
   if (process.env.NODE_ENV === 'production' && (hasWeb || hasShop)) {
     const webStatic = hasWeb ? express.static(webDist) : null;
     const shopStatic = hasShop ? express.static(shopDist) : null;
     app.use((req: Request, res: Response, next: NextFunction) => {
       const handler = isShopHost(req.headers.host) ? shopStatic : webStatic;
       if (!handler) return next();
       return handler(req, res, next);
     });
     ...SPA fallback...
   }
   ```
   KHÔNG dùng `app.useStaticAssets(webDist)` nữa cho phần này — nó mount cố định một thư mục, không chọn được theo host. `useStaticAssets` cho `/uploads/` ở dòng 35 **giữ nguyên**.

4. SPA fallback: giữ nguyên toàn bộ logic hiện có (check `req.method !== 'GET'`, `req.path.includes('.')`, `Accept: text/html`, `apiPrefixes`), chỉ đổi mọi `join(webDist, 'index.html')` thành `join(dist, 'index.html')` với
   `const dist = isShopHost(req.headers.host) ? shopDist : webDist;` tính ở đầu handler.
   Nếu dist tương ứng không tồn tại (`!existsSync(dist)`) → `next()`, đừng `sendFile` vào hư không.

5. **THÊM `'/api'` vào đầu mảng `apiPrefixes`.** (Bản đầu của plan này nói ngược lại — đã sửa sau khi test thật.)
   Nest đăng ký router trong `app.init()` (bên trong `listen()`), tức **sau** mọi `app.use()` ở `bootstrap()`,
   nên middleware fallback đứng TRƯỚC router. Thiếu `'/api'` → `GET /api/public/*` trả `index.html` thay vì JSON,
   kể cả với `Accept: application/json`. Bug này có sẵn từ Milestone 1 và sẽ chết toàn bộ endpoint khách của phase 8–9.
   Ghi comment nêu rõ cơ chế + việc đã dựng lại được bằng curl, để người sau không xoá.
