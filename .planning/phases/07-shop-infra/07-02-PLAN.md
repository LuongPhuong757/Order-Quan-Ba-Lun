**`parseAllowedOrigins`:**
- 1 origin đơn: `'https://quanbalun.site'` → `['https://quanbalun.site']`
- 2 origin: `'https://quanbalun.site,https://order.quanbalun.site'` → 2 phần tử
- có khoảng trắng thừa: `' https://a.com , https://b.com '` → trim đúng, 2 phần tử
- có dấu `/` cuối: `'https://a.com/'` → `['https://a.com']`
- phần tử rỗng do dấu phẩy thừa: `'https://a.com,,'` → 1 phần tử
- chuỗi rỗng / undefined → `[]`

**`isOriginAllowed`:**
- khớp chính xác → `true`
- origin thứ hai trong list → `true` (đây là điểm chính của M2.D-67)
- **prefix-spoof `'https://quanbalun.site.evil.com'` với list `['https://quanbalun.site']` → `false`** ← lý do tồn tại của test này
- **`'https://quanbalun.sitex.com'` → `false`**
- khác protocol: `'http://quanbalun.site'` với list `['https://quanbalun.site']` → `false`
- khác port: `'http://localhost:5174'` với list `['http://localhost:5173']` → `false`
- Referer có path: `'https://order.quanbalun.site/checkout?x=1'` với list chứa `'https://order.quanbalun.site'` → `true` (Referer mang path, phải so theo origin)
- input rác: `'not-a-url'`, `''`, `undefined` → `false`, và **không throw**
- list rỗng → mọi origin `false`

```ts
// M2.D-67 + C-SEC-01 — allow-list origin dạng danh sách, so khớp CHÍNH XÁC.
// Bản cũ dùng origin.startsWith(allowed) nên https://quanbalun.site.evil.com lọt qua:
// không có ranh giới sau phần prefix. Ở đây so protocol + '//' + host bằng đúng bằng.

export function parseAllowedOrigins(raw: string | undefined): string[] { ... }
export function isOriginAllowed(originOrReferer: string | undefined, allowed: string[]): boolean { ... }
```

`parseAllowedOrigins`: split `','` → `trim()` → bỏ rỗng → bỏ `/` cuối (`replace(/\/+$/, '')`).

`isOriginAllowed`: nếu `!originOrReferer` → `false`. Bọc `new URL()` trong `try/catch`, catch → `false` (D-09). Chuẩn hoá thành `url.protocol + '//' + url.host` (dùng `host` chứ **không** phải `hostname` — `host` giữ port, cần để phân biệt `localhost:5173` với `localhost:5174`). So `allowed.includes(normalized)`.

Chuẩn hoá cả phía allow-list qua cùng một hàm để `'https://a.com/'` và `'https://a.com'` khớp nhau.

Chạy `pnpm test` tới khi **xanh**. Không sửa test để làm nó xanh — sửa implementation.
