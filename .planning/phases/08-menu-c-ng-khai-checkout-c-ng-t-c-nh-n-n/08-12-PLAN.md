  <action>
    Tạo `maps-link.ts` với `export function parseMapsLink(raw: string): { lat: number; lng: number } | { error: 'SHORT_LINK' | 'NO_COORDS' }`.
    Thi công **100% client-side bằng regex**, theo đúng thứ tự ưu tiên:
    1. `!3d(-?\d+(?:\.\d+)?)!4d(-?\d+(?:\.\d+)?)` — toạ độ chính xác của địa điểm (ưu tiên cao nhất).
    2. `@(-?\d+(?:\.\d+)?),(-?\d+(?:\.\d+)?)` — tâm khung nhìn.
    3. `[?&]q=(-?\d+(?:\.\d+)?),\s*(-?\d+(?:\.\d+)?)` — tham số `q`.
    4. `^\s*(-?\d+(?:\.\d+)?)\s*,\s*(-?\d+(?:\.\d+)?)\s*$` — khách dán thẳng cặp số.
    Kiểm dải: `lat` ∈ [-90, 90], `lng` ∈ [-180, 180]; ngoài dải → `NO_COORDS`.
    Nhận diện link rút gọn trước khi kết luận `NO_COORDS`: host chứa `maps.app.goo.gl` hoặc `goo.gl` →
    `{ error: 'SHORT_LINK' }` để UI hiện thông báo đúng nguyên nhân.

    follow redirect**. Link rút gọn `maps.app.goo.gl` **cố ý không hỗ trợ** (Assumptions Log A3): resolve
