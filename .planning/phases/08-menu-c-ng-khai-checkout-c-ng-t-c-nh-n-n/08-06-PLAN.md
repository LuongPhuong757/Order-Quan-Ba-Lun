       — `fetch(path, { headers: { Accept: 'application/json' } })`; đọc JSON; nếu `res.ok` thì
       `schema.safeParse(json.data)`, thất bại → `error.kind='schema'`; nếu không ok thì parse

    3. `postJson<T>(path: string, body: unknown, schema: ZodType<T>): Promise<{ data: T } | { error: ApiError }>`
